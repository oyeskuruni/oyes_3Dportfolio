# Oyes Kuruni — Premium 3D Personal Portfolio Website

A modern, high-performance 3D personal portfolio engineered for **Oyes Kuruni**, showcasing multidisciplinary expertise as a **Web Developer, Web Analyst, and Digital Marketer**.

Built with:
- **React 19** + **Vite 8**
- **Tailwind CSS v4** (Dark & Light theme support with frosted glassmorphism)
- **React Three Fiber** (`@react-three/fiber`, `@react-three/drei`, `three`) for interactive 3D WebGL core & particle physics
- **GSAP** (`gsap`, `@gsap/react`) for smooth entrance, staggered reveals, and magnetic cursor button physics
- **Canvas Confetti** for interactive certificate credential reveals

---

## 🌟 Key Features

1. **Interactive 3D Hero Section**:
   - Central **Holographic Data Core** (icosahedron wireframe + inner pulsating energy orb + dynamic gyroscopic rings) that tracks cursor movement.
   - **Floating 3D Orbit Nodes** for **GA4**, **GTM**, **Google Ads**, **Meta (CAPI)**, and **Shopify** with interactive HTML metadata cards and hover glow.
   - 1,100+ ambient floating particle starfield with additive blending.
   - Automatic fallback for non-WebGL environments and responsive camera adaptation for mobile.

2. **Web Analytics Deep Dive**:
   - Case studies detailing Server-Side GTM on GCP Cloud Run, GA4 to BigQuery streaming pipelines, Headless Shopify DataLayer reconciliation, and global Consent Mode v2.
   - Architectural flow charts, business ROI metrics (+38% conversion recovery, 9.7 EMQ, 99.9% Stripe match).

3. **Web Development Showcase**:
   - Full-stack SaaS dashboards, headless e-commerce storefronts, 3D interactive experiences, and developer tooling.
   - Live demo links, GitHub code buttons, and Core Web Vitals scorecards (100/100, 98 Mobile PageSpeed).

4. **Official GA4 & Ad Tech Certifications**:
   - Featured **Google Analytics 4 Individual Qualification** spotlight.
   - Interactive verification cards for GTM Advanced, Google Ads Measurement, Meta Blueprint, and Shopify Partner.
   - Interactive **Certification Modal** with official credential IDs, syllabus competencies, direct registry verification links, and a canvas confetti celebration.

5. **Skills Matrix**:
   - Categorized across Web Dev, Web Analytics, Ad Tech / Marketing, and Cloud Infrastructure.
   - Visual proficiency indicators and highlight tags.

6. **Interactive Experience & Contact**:
   - Quantified milestone timeline across high-growth agencies.
   - Interactive project inquiry form with real-time feedback.
   - Copy-to-clipboard email utility and response time commitment.

## 🚀 Quick Start

```bash
# Navigate to project directory
cd C:\Users\pc\.gemini\antigravity\scratch\oyes-kuruni-portfolio

# Install dependencies (already installed)
npm install --legacy-peer-deps

# Start development server
npm run dev

# Build for production
npm run build
```
